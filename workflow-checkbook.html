What this demonstrates

The same assertions detect planted defects and pass the corrected reference. Inputs, response fields and side-effect counts remain visible in the exported report.

What it does not establish

This is an independent JavaScript fixture, not a test of n8n, Vapi, Twilio, ElevenLabs or a customer's agent. It does not assess voice quality or model behavior. State is in memory; concurrent requests and recovery after a process restart are outside this example. The timeout is injected before a destination write. An unknown outcome after a write requires reconciliation and is not covered.
