01 / GEOMETRY

Measure the gap between meshes.

Import a pair of local STL files, move one mesh and inspect the nearest surface points. Invalid files leave the prior models intact; slow queries stop with an explicit unavailable result.

17 automated checks. Browser-checked STL import, malformed input, query timeout, reset, JSON export and narrow layout.

Open Mesh Surface Probe →Source + fixtures
Scope and limits

Rigid transforms; generated boxes and spheres only. Surface intersection does not detect solid containment. No registration, clinical or manufacturing validation. 6 MiB and 20,000 triangles per file are resource limits, not performance guarantees. Queries use Three.js and three-mesh-bvh; third-party notices.

02 / WORKFLOW QA

A successful request can still do the wrong thing.

Run twelve synthetic cases against intentionally defective and corrected fixtures. Inspect responses alongside actual effect counts, then export the observations.

Before: 1/12. After: 12/12. A separate local n8n + SQLite check covers 14 cases in 19 executions, including post-write timeout and replay after restart.

Open Workflow Checkbook →Source + n8n evidence
Scope and limits

The browser runs an in-memory JavaScript fixture, not n8n or a customer service. The downloadable n8n evidence is a separate loopback test. It does not establish production readiness or exactly-once effects in outside services. No voice/LLM evaluation.

03 / PARAMETRIC LAYOUT

Keep the spacing rule at the boundary.

Set a usable length, fixed motif width and maximum gap. Compare two explicit end-gap rules and export an SVG with millimetre dimensions plus a table of positions.

23,496 combinations checked against an independent brute-force calculation. Actual SVG/CSV downloads and the count change at 1200.001 mm were verified.

Open Pattern Spacing Lab →Source + exported examples
Scope and limits

Rectangular synthetic motifs only. Exact integer micrometres determine the count; exported positions are rounded to six decimal millimetres. No DXF, decorative library, physical cutting or customer-equipment validation.

04 / ASYNC JOB STATE

A late result should stay in its own attempt.

Deliver callbacks out of order, replay a success, cancel a job, then retry it. A local SQLite ledger records each decision and prevents an older attempt from overwriting the new result.

19 tests and 4 browser scenarios. Concurrent duplicates, conflicting event ids, service restart and malformed inputs were checked. Chinese and emoji results survive persistence. Python standard library only.

Download & run locally →README included
Run locally · scope and limits

Requires Python 3.10+. Extract the archive, open the shot-ledger folder, run python -m unittest -v, then python server.py. Open http://127.0.0.1:8846/ and choose Run all four checks. Stop with Ctrl+C. Full instructions are in README.md.

This sample needs its local Python service; the image is a captured demonstration, not a hosted backend. No model, media, provider or billing calls. A cancelled ledger entry does not cancel a provider operation. No production queue or distributed exactly-once claim.
